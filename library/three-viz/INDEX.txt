Bundled Three.js Visualization Library

Purpose

This directory is the reusable browser library in this repository. Apps in this repository and local development tools in the sibling `Tools/` folder import it through relative paths.

Modules

- src/index.js: public exports, including mount, plotters, validation, mapping, and resource tools.
- src/utils/: reusable color helpers, including evenly spaced rainbow palettes and single-hue light-to-dark shades.
- `generateColorShades(color, count, { lightnessStart, lightnessEnd })` returns shades ordered evenly from the starting lightness to the ending lightness while retaining the input hue. The default range starts at lightness 0.72 for a darker, still visibly blue light shade and ends at 0.38.
- `createCarPaintMaterial(THREE, color, options)` supplies shared metalness-1 materials with minimum clearcoat gloss and polish settings; `retainCarPaintEnvironment(THREE, scene, renderer)` shares a generated softbox environment across plotters attached to that scene.
- src/core/: viewer lifecycle, errors, and resource ownership.
- src/data/: input validation and coordinate mapping.
- src/plotters/: bar-chart, point-cloud, CSV bars, scatter, histogram, surface, trajectory, vector-field cone, ConeIso, time-slice, isosurface, and weather-tube plotters; each implementation has its own JavaScript module.
- `src/plotters/vector-field-plotter.js` places an instanced cone at each valid vector sample. Cone height scales linearly with magnitude; its diameter is half its height.
- `src/plotters/cone-iso-plotter.js` extracts an isosurface, filters facets by minimum area, samples the local field direction at each retained facet center, and places instanced cones without drawing the isosurface.
- src/plotters/shared/: CSV mapping support plus reusable wireframe and marching-tetrahedra isosurface geometry helpers.
- src/objects/: reusable labeled boxes and 2D/3D grids. Grid components remain separate from plotter implementations.
- tests/: local development tests; the website does not import these files.

Runtime

The Weather app imports ../../library/three-viz/src/index.js. Its HTML import map pins Three.js and OrbitControls to 0.186.0 on jsDelivr. The library runtime itself is native JavaScript ES modules and does not require a build step or package installation.
