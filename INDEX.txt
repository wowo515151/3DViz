3DViz Repository Index

Purpose

This folder is the local, reviewable content for the public wowo515151/3DViz repository. It bundles the shared Three.js plotter library source and the Weather preview app in one self-contained repository. The CSV and weather-signal development tools remain under the sibling `Tools/` folder and import the library by relative path.

Tree

- README.md: status, repository description, run instructions, app list, dependency notes, and license reference.
- LICENSE: repository MIT license.
- index.html: animated GitHub Pages landing page with links to apps.
- style.css: responsive landing page styling and reduced-motion handling.
- apps/weather/: runnable 3D Weather UI and its local application modules.
- library/three-viz/src/: browser library modules, with one file per plotter and shared wireframe/isosurface helpers.
- library/three-viz/tests/: library development tests; not loaded by the site.
- library/three-viz/package.json: native ES module metadata for local test execution.

Paths

- Landing page: /
- Weather app: /apps/weather/3dWeather.html
- Weather app imports the shared library from ../../library/three-viz/src/index.js.

Release notes

- Only repository contents belong here; workspace planning, review, and traffic records remain outside the repository.
- `library/three-viz/` is the canonical plotter library in this repository.
- Three.js 0.186.0 loads from pinned jsDelivr runtime URLs; its source is not bundled.
- CSV and weather signal tools consume plotter modules from this repository through sibling workspace paths. They are local development tools and are not hosted by this repository.
- Human visual review and explicit approval are required before public upload.
